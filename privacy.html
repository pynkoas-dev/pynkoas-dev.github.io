Политика конфиденциальности

Дата вступления в силу: 21.10.2026

«Claude Tasks» — личное приложение одного пользователя (владельца), не предназначенное для третьих лиц.

  • Какие данные используются. Только Google Задачи владельца (область доступа https://www.googleapis.com/auth/tasks): названия, заметки, сроки и статусы задач и списков.
  • Зачем. Чтобы по запросу владельца просматривать, создавать, изменять, переносить и отмечать выполненными задачи через ассистента Claude.
  • Хранение. Приложение не хранит содержимое задач. Хранится только OAuth-токен доступа на устройстве или сервере владельца.
  • Передача. Данные не продаются и не передаются третьим лицам, кроме передачи ассистенту Claude (Anthropic) в рамках запросов самого владельца.
  • Отзыв доступа. Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.

Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Privacy Policy (English)

Effective date: October 21, 2026

"Claude Tasks" is a personal, single-user application used only by its owner.

  • Data accessed: only the owner's Google Tasks (scope https://www.googleapis.com/auth/tasks): task and list titles, notes, due dates and status.
  • Purpose: to list, create, update, move and complete tasks via the Claude assistant at the owner's request.
  • Storage: task content is not stored; only the OAuth access token is kept on the owner's own device or server.
  • Sharing: data is not sold or shared with third parties, except being passed to the Claude assistant (Anthropic) as part of the owner's own requests.
  • Revoking access: at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
